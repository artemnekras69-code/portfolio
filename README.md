# Портфолио Артёма Некрасова

Одностраничный сайт без сборки и без зависимостей: HTML, CSS и один скрипт.

## Как посмотреть

Откройте `index.html` двойным кликом — сайт работает прямо с диска.
Шрифты подгружаются из Google Fonts, поэтому нужен интернет; без него включатся системные запасные шрифты.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Вся разметка и все тексты. Секции подписаны комментариями: обложка, цифры, образование, кейсы, ирония, навыки, контакты |
| `css/base.css` | Цвета, шрифты, кнопки, навигация, появление при прокрутке |
| `css/sections.css` | Все секции, кроме кейсов |
| `css/cases.css` | Три кейса и переключатель между ними |
| `js/app.js` | Поведение: вступление, счётчики, меню, карточки «на слайдах / в жизни», анимация мема |
| `assets/img/` | Фотографии и картинка для превью ссылки |
| `assets/cv/` | CV на английском, на него ведёт ссылка в контактах |

## Как заменить фотографии

- `assets/img/artem-cutout.webp` — портрет на обложке. Нужен файл с прозрачным фоном, нижний край обрезан ровно.
- `assets/img/artem-diploma.webp` — фото с дипломом в блоке «Образование». Обычный прямоугольный кадр, пропорции 4:5.
- `assets/img/og.jpg` — картинка, которую мессенджеры показывают при отправке ссылки, 1200×630.

Если у новых файлов другие размеры, поправьте `width` и `height` у соответствующих `<img>` в `index.html`.

## Как дополнить кейс про Telegram-бота

В кейсе есть «спецификация продукта» из шести полей. На сайте видны только заполненные.
Пустые поля показываются в режиме черновика: откройте страницу с `?draft` в адресе (`index.html?draft`).

Чтобы опубликовать поле:

1. Найдите в `index.html` блок `<div class="spec__row" data-empty>` с нужным заголовком.
2. Впишите текст в `<p class="spec__text">`.
3. Удалите атрибут `data-empty` — поле появится на сайте.

Вписывайте только подтверждённые данные.

## Публикация

Сайт опубликован на GitHub Pages: https://artemnekras69-code.github.io/portfolio/

Репозиторий: `git@github.com:artemnekras69-code/portfolio.git`. Pages собирает сайт из ветки `gh-pages`, поэтому после правок нужно отправить коммит в обе ветки:

```bash
git push origin main main:gh-pages
```

Если сайт переедет на другой адрес, поменяйте его в тегах `og:url` и `og:image` в начале `index.html`, иначе мессенджеры не покажут превью ссылки.
